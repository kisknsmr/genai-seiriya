# 生成AI整理屋さん

AI チャットの会話をまとめて保存する Chrome 拡張機能です。
**Gemini / ChatGPT / Claude** に対応しています。

**最新版: v1.4.3**（2026-10-11）　→ [ダウンロード](../../releases/latest)

## できること

- 全会話（または選んだ会話）を一括保存
- 保存形式
  - **Markdown（.md）**：Obsidian などでそのまま読めます
  - **HTML**：各サービス風の見た目で、ブラウザで読めます（`index.html` に一覧付き）
- 結果は 1 つの ZIP ファイルでダウンロードされます
- 通信エラーでも諦めず、最大20回（約17分）まで待って再試行します
- 失敗した会話は最後にもう一度挑戦し、それでもダメなら ZIP 内の `errors.txt` に記録します
- 一覧の読み込みが止まっても「続きを読み込む」で途中から再開できます
- **選んだ会話の一括削除**（「保存してから削除」も選べます）

### サービスごとの対象

| サービス | 一覧に含まれる会話 |
|---|---|
| Gemini | すべての会話 |
| ChatGPT | 通常の会話・アーカイブ済み・プロジェクト内（自分のプロジェクト） |
| Claude | すべての会話（プロジェクト内を含む） |

会話を枝分かれさせた場合（回答の再生成・質問の編集）は、最後に表示していた流れを保存します。
Claude のアーティファクトは、中身をコードブロックとして保存します。

## インストール

1. [Releases](../../releases) から `genai-seiriya-v<バージョン>.zip` をダウンロードし、展開する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」で、展開した `genai-seiriya` フォルダを選ぶ

> 更新するときは、新しい ZIP を同じ場所に展開し直し、`chrome://extensions` で再読み込み（↻）を押します。

## 使い方

1. Gemini / ChatGPT / Claude のどれかを開く（ログイン済みであること）
2. サイドバー上部、ロゴのすぐ右にある「一括保存」アイコン（⬇）を押す（シークレットチャット中は表示されません）
3. 保存したい会話にチェックを入れ、形式を選んで「保存する」
   - Shift を押しながらクリックすると、前にクリックした行からその行までをまとめて選べます
   - キーボードでは ↑↓ で移動、Shift+↑↓ で選びながら移動、Space で切り替えできます

> 補足: 各サービスの回数制限を超えないよう、1 件あたり約 1〜1.3 秒かけて取得します。
> 500 件なら約 9〜11 分かかります。途中で「中止」すると、それまでの分を保存します。

### 会話を削除する

1. パネルで削除したい会話にチェックを入れる
2. 「削除する」を押す
3. 確認画面で選ぶ
   - **保存してから削除**（おすすめ）：先に ZIP で保存し、保存できた会話だけを削除します
   - **削除のみ**：保存せずに削除します
   - **キャンセル**：何もしません

> ⚠️ 削除した会話は元に戻せません。
> ChatGPT は画面の「削除」と同じ操作（非表示化）を行います。
> 削除後、サイドバーの表示はページを再読み込みすると更新されます。

## フォルダ構成（開発者向け）

```
manifest.json
icons/                     アイコン画像
scripts/make-icons.ps1     アイコン画像を作り直す
scripts/build.ps1          配布用 ZIP を作る（dist/ に出力）
src/core/net.js            通信の共通部品（間隔調整・再試行・中止）
src/core/zip.js            ZIP 作成（外部ライブラリなし）
src/core/markdown.js       Markdown → HTML 変換
src/core/exporters.js      会話 → .md / .html（全サービス共通）
src/platforms/gemini.js    Gemini から会話を取得
src/platforms/chatgpt.js   ChatGPT から会話を取得
src/platforms/claude.js    Claude から会話を取得
src/content/ui.js          ボタンとパネル（全サービス共通）
```

新しいサービスを足すときは `src/platforms/` に取得処理を追加し、`manifest.json` に URL を追加します。

## 配布・リリース手順（開発者向け）

1. `manifest.json` の `version` を上げる
2. README の「最新版」の行と「更新履歴」を書き足す
3. PowerShell で `powershell -ExecutionPolicy Bypass -File scripts/build.ps1` を実行
4. コミットして push する
5. `gh release create v<バージョン> dist/genai-seiriya-v<バージョン>.zip` で GitHub にリリースを作る

> ⚠️ 5 を忘れると、GitHub の Releases は古い版のままになります。

## プライバシー

会話の内容を外部に送信しません。詳しくは [PRIVACY.md](PRIVACY.md) を参照してください。

## 注意

- 各サービスの非公開 API を使っているため、仕様変更で動かなくなる可能性があります。
- 画像・添付ファイルの中身は保存対象外です（テキストのみ。添付はファイル名だけ記録）。
- 本ツールは各サービスの公式ツールではありません。利用は自己責任でお願いします。
